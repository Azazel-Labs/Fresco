# Fundamentals Curriculum

Goal: each example demonstrates one primary concept with minimal extra machinery.

## Ordered Starter Track

Run these first, in order, for the language feature ramp:

- `01_fn_basics.fr`: define and call a top-level function.
- `02_callable_parameter_basics.fr`: pass a function reference as a callable parameter.
- `03_generic_typevar_basics.fr`: generic `<T>` type-variable flow through a function.
- `04_interface_bound_basics.fr`: interface + conformance + bounded generic (`<T: Bound>`).
- `05_enum_typed_declaration_basics.fr`: enum declaration and enum-typed locals.

## Core Concepts

- `badge.fr`: shape plus fill baseline.
- `sunset.fr`: layered composition with simple gradients.
- `color_component_mix.fr`: color channel composition basics.
- `color_gradient_bands.fr`: stop-based gradient construction.
- `blend_modes_comparison.fr`: blend mode behavior in one scene.
- `stroke_outline_panel.fr`: stroke and outline fundamentals.
- `shape_boolean_cutout.fr`: boolean shape operations.
- `shape_morph_mix.fr`: shape interpolation baseline.
- `shadow_offset_card.fr`: shadow offset and softness fundamentals.
- `glow_beacon.fr`: glow as a local effect baseline.
- `blur_soften_haze.fr`: blur/soften relationship.
- `effects_new_stack.fr`: effect pipeline composition basics.
- `effects_smooth_warning.fr`: smooth/effect diagnostics baseline.
- `gridlines.fr`: simple procedural line patterning.
- `repeat_grid_dots.fr`: rectangular repeat fundamentals.
- `repeat_cell_polka.fr`: repeat-cell binding basics.
- `centered_fit_fill_panels.fr`: centered/aspect mapping basics.
- `rotate_around_pivot.fr`: transform around custom pivot.
- `wave_saw_square.fr`: waveform shape fundamentals.
- `wave_triangle_motion.fr`: triangle wave motion behavior.
- `sine_phase_offsets.fr`: phase-offset signal basics.
- `for_loop_bars.fr`: compile-time loop fundamentals.
- `param_array_positions.fr`: parameter array indexing basics.
- `scatter_index_phase.fr`: scatter index-driven variation.
